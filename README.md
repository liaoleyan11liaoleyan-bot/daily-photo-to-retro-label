# Daily Photo to Retro Label

一个 Codex skill：把用户上传的日常照片整理成横版档案纸作品，并将照片中的主体转译为小型、无字、有限色套印的中式复古酒标。

## 视觉结果

- 1536 × 1152 px、4:3 横构图
- 左侧为忠实保留的真实照片，使用自然撕边
- 右侧为暖白档案纸、大面积留白和角落酒签组
- 酒标内部不使用文字，以边框、色带、景观窗和装饰纹样保留老酒标的设计层次
- 酒标外使用小号、褪色的中文打字机文字

## 安装

将整个仓库复制到 Codex skills 目录：

```bash
git clone https://github.com/liaoleyan11liaoleyan-bot/daily-photo-to-retro-label.git
cp -R daily-photo-to-retro-label ~/.codex/skills/
```

重新启动 Codex 或开启新任务，使 skill 被重新发现。

## 使用

### 1. 准备图片

- **必须上传：** 1 张需要处理的日常照片。照片是画面主体、器物、人物、植物及颜色的唯一内容来源。
- **可以上传：** 1–3 张中式老酒标参考图，用来指定酒标的轮廓、边框层次、色带、版面分区和有限色套印方式。参考图只提供视觉形式，不会复制其中的品牌、文字、商标、地标或其他具体内容。
- 如果同时上传多张图片，请明确说明哪张是“日常照片”，哪些是“酒标参考图”。没有酒标参考图也可以使用，skill 会按照 `SKILL.md` 中的老酒标造型规则完成设计。

### 2. 调用 skill

上传图片后，在同一条消息中明确写出 skill 名称和制作要求。最简用法可以直接复制：

> 请使用 `daily-photo-to-retro-label`，把我上传的日常照片制作成横版档案纸作品。日常照片是内容来源；如有其他图片，它们只作为中式老酒标的形式参考。

如果希望指定酒标外的文字，可以这样写：

> 请使用 `daily-photo-to-retro-label` 处理这张日常照片。酒标内部不要文字；酒标外第一行写“小珠微光”，第二行写“清甜一杯”。

还可以指定酒签组的位置、酒标外形或希望重点提取的元素，例如：

> 请使用 `daily-photo-to-retro-label`。从日常照片中提取高脚杯和彩色珠粒，制作矩形无字复古酒标；酒签组放在右下角。其余版式、纸张、撕边和印刷质感按照 skill 默认规则执行。

没有指定外部文案时，skill 会根据照片拟定简短的中文观察文字；不会猜测未确认的日期、地点、品牌、配方或酒精度。

### 3. 默认输出

默认交付一张 1536 × 1152 px、4:3 横版成图：整幅为暖白档案纸，左侧放置忠实保留的撕边原照片，右侧角落放置一枚从照片提炼的完整无字复古酒标，并在酒标外安排 1–2 行小号中文打字机文字。最终同时提供可用的图片文件链接。

详细规则见 [SKILL.md](SKILL.md)。

## 参考图片

本仓库当前不附带第三方酒标图片。请使用自己拥有发布和使用权限的参考素材；参考图只用于提取版式、边框、色块和印刷语言，不复制品牌、厂名、商标或其他识别信息。
